
# Airbound Moderation

The official Discord bot for the Airbound community.

## Features planned

- Roblox account linking and verification
- Roblox profile lookup
- Support ticket management
- Moderation commands
- Staff logging
- Roblox group membership checks
- Application system
- Giveaway system
- Rank and statistics

## Runtime

- Node.js 24 LTS
- discord.js
- Environment variables for secrets

## Start command

npm start
